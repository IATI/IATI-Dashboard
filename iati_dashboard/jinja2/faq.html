Who runs the IATI Dashboard?

The IATI Dashboard and Publishing Statistics are maintained by the IATI Secretariat and includes components developed by Code for IATI volunteers. The IATI Dashboard tracks and provide metrics about how IATI data is published and how the IATI Standard is used in practice.

When is the Dashboard updated?

The Dashboard and Publishing Statistics are generated through a process that happens once every 24 hours.

This is a two step process:

  1. First, all registered data is downloaded — see the “data downloaded” timestamp in the footer of each page.
  2. From this dataset, the relevant statistics are calculated, and this site is then updated — see the “generated” timestamp in footer.

The process usually completes within 12 hours.

Why is there a difference between the data download and Dashboard generation time?

The data is downloaded, and then there is a period of computing time to generate the statistics that inform the Dashboard and Publishing Statistics.

Usually, there is a short period of time between the two. However, we do track this as sometimes things break and the site may fail to regenerate. If you spot something, please contact us to let us know.

What do the Publishing Statistics numbers mean?

The tables show how timely, forward looking and comprehensive a publisher's IATI data is. A summary of this information is displayed on the Summary Statistics page.

The other tabs outline how this mark is calculated and the different assessments included.

Only the timeliness tables track an organisation's publishing over time. If the Publishing Statistics doesn't pick up your data one month we are unable to back fill the table.

Can I build my own version of this Dashboard?

Yes — the source code is all open source:

  1. https://github.com/IATI/IATI-Dashboard/.

How can I suggest a new function?

You can open a GitHub Issue or contact us to discuss your suggestion.

The Dashboard doesn't accurately reflect our data

There are three checks that you can make:

  1. Is the data registered?
  2. Has this site updated since you published (check the timestamps in the footer of this page)?
  3. Is your data freely available for download, without blocking that might affect automated tools such as the IATI Dashboard?

If none of these apply or you have other questions, please contact us.

I want to get to the data of a publisher — how can I do that?

Visit the Dashboard page for the publisher. Alternatively, see the IATI website for details of various tools to access data.
